# WezTerm 功能清单与使用说明

---

## 第一优先级：日常基础

| 功能 | 怎么做 | 有什么用 |
|------|--------|----------|
| **标签页** | `Ctrl+Shift+T` 新建，`Ctrl+Shift+1`～`4` 切换 | 一个窗口开多个 WSL 会话 |
| **分屏** | `Ctrl+Shift+L` 左右分，`Ctrl+Shift+Enter` 上下分 | 一边看日志一边写代码 |
| **复制粘贴** | 鼠标选中文本即复制，`Ctrl+Shift+V` 粘贴 | 不用右键菜单 |
| **窗格跳转** | `Ctrl+Shift+方向键` | 在分屏间快速移动光标 |
| **全屏沉浸** | `Alt+Enter` | 去除边框，专注写代码 |

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| **工作区切换/创建** | `Ctrl+Shift+F9` | 输入名称切换或创建新工作区 |
| **智能工作区选择器** | `Ctrl+Shift+Alt+F9` | 显示已保存的工作区列表，输入编号或名称切换 |

### 状态栏显示

右上角状态栏只显示：`工作区名 · 电量 · 时间`。Git 后台轮询默认关闭。

### 内置快速跳转项目

这些是 `.wezterm.lua` 中的静态别名，不会调用 zoxide；换机器或调整目录后需要同步修改。

| 项目名 | 对应路径 |
|--------|----------|
| `obsidian` | `/home/lenovo/project/Obsidian` |
| `wezterm` | `/mnt/e/WezTerm` |
| `dotfiles` | `/home/lenovo/project/dotfiles` |

### 使用方法

1. **创建工作区**：`Ctrl+Shift+F9` → 输入名字（如 `project-a`）
2. **智能切换**：`Ctrl+Shift+Alt+F9` → 看到工作区列表，输入编号或名称切换
3. **快速跳转**：`Ctrl+Shift+Z` → 输入项目名（如 `obsidian`）直接跳转
4. **记录信息**：调整好工作区后按 `Ctrl+Shift+Alt+S` 写入当前元数据
5. **恢复入口**：智能选择已保存工作区时，尝试从记录的首个目录启动；不会自动重建原分屏和进程

## 第四优先级：工作区式会话管理（不是 tmux 持久会话）✅ 已配置

### 两种操作方式

| 操作方式 | 触发方法 |
|---------|---------|
| **右键菜单** | 在终端区域点击鼠标右键 |
| **快捷键** | 按对应的键盘组合键 |

### 和「桌面右键」是不是同一种界面？

**不是同一种东西，但流程可以类比。**

- 在 **Windows 桌面 / 文件夹空白处** 右键，弹出的是 **操作系统（资源管理器）画出来的原生菜单**：圆角、亚克力/云母、图标、子菜单，那是 **Explorer + WinUI/壳** 提供的，**不是** 终端程序自带的控件。
- 在 **WezTerm 终端区域** 右键，弹出的是 WezTerm 自己的 **InputSelector**：终端里叠一层 **文字列表**（上面那句英文提示 + 用 ↑↓ 选、回车确认）。**交互**上可以当成「先右键再选功能」，和桌面一样是分步操作；**长相**做不到和桌面右键 **100% 一样**，因为 WezTerm **目前不能在窗口里嵌入与桌面完全相同的 Win32 右键菜单**。这不是配置写错，是这类终端模拟器的普遍限制。
- 若你更看重 **和系统一模一样的菜单外观**：在 **真实桌面或文件夹里** 用右键（例如已提供的「在此处打开 WezTerm」注册表思路），或接受终端内为 **列表式菜单**；**功能**（分屏、工作区等）仍通过当前右键列表完成。

### 功能列表

| 功能 | 右键菜单 | 快捷键 | 说明 |
|------|---------|--------|------|
| **左右分屏** | 右键 → 左右分屏 | `Ctrl+Shift+L` | 创建左右分屏 |
| **上下分屏** | 右键 → 上下分屏 | `Ctrl+Shift+Enter` | 创建上下分屏 |
| **关闭窗格** | 右键 → 关闭当前窗格 | `Ctrl+Shift+W` | 关闭当前分屏 |
| **新建标签** | 右键 → 新建标签 | `Ctrl+Shift+T` | 创建新标签页 |
| **切换/创建工作区** | 右键 → 切换或创建工作区… | `Ctrl+Shift+F9` | 先选菜单项，再输入名称 |
| **记录工作区** | 右键 → 记录当前工作区 | `Ctrl+Shift+Alt+S` | 记录当前标签、窗格、目录和 domain 元数据 |
| **列出工作区** | 右键 → 列出所有工作区 | `Ctrl+Shift+M` | 显示所有工作区 |
| **快速切到已保存工作区** | （菜单无此项） | `Ctrl+Shift+A` | 切到未排序列表里的第一个已保存工作区；目标不保证固定 |
| **记录并关闭** | 右键 → 记录工作区并关闭本窗口 | `Ctrl+Shift+D` | 记录元数据后关闭窗口，不承诺后台进程持久化 |
| **新建窗口** | 右键 → 新建独立窗口 | `Ctrl+Shift+Alt+N` | 创建新的 WezTerm 窗口 |

> 安全提醒：当前所有关闭窗格/窗口动作都不弹确认框，误触会直接终止其中的前台任务。

### 使用方法（右键菜单方式）

这就是你要的效果：**在终端里右键 → 出列表 → 选功能 → 有的会再问一句**（和下面步骤一致）。

1. **在终端画面里（有光标、能打字的那块区域）点一下右键并松开**（配置为**松开右键**时出菜单，**不必一直按着**右键再选；不要在 Windows 桌面空白处点——那是系统菜单，不是 WezTerm）。
2. 菜单标题会提示键盘操作。用 **↑↓** 移到要用的那一项，按 **Enter** 确认；想关掉菜单不操作时：按 **Esc**，或选最后一项 **「退出菜单」**。
3. **例如切换/创建工作区**：选 **「切换或创建工作区…」** → 回车后会出现输入框 → **输入工作区名字**（如 `project-a`）→ 再回车，即切换到该工作区（没有这个名字会自动建一个）。
4. **例如左右分屏**：选 **「左右分屏」** → 回车，当前窗格会立刻左右分屏（无需再输入）。
5. **记录与再次进入（可选）**
   - 右键 → **记录当前工作区**（或 `Ctrl+Shift+Alt+S`）会记录工作区元数据
   - 需要关窗口时：右键 → **记录工作区并关闭本窗口**
   - 下次打开 WezTerm 后，可以再次切换到同名工作区；当前实现只尝试恢复首个入口目录

**若右键仍是旧菜单或没反应：** 确认 WezTerm 读的是当前这份配置（例如 `C:\Users\lenovo\.wezterm.lua` 与仓库里 `e:\WezTerm\.wezterm.lua` 已同步），然后 **完全退出 WezTerm 再打开**，或 `Ctrl+Shift+R` 重载配置。

### 使用方法（快捷键方式）

适合键盘党，按相应快捷键直接触发功能。

### 工作区式会话管理的实际边界

当前方案适合整理窗口与入口目录，但不能替代 tmux 的进程持久化：

1. **创建专用工作区**：按项目或任务命名工作区，例如 `training`
2. **切换工作区**：在同一 WezTerm mux 进程内切换不同工作区
3. **记录信息**：JSON 会保存标签、窗格、cwd 和 domain 元数据
4. **受限恢复**：再次进入时尝试使用首个 cwd，不重建标签、分屏比例或运行进程
5. **后台存活**：本仓库没有配置独立 mux server；需要持久会话时使用 tmux 等专用工具

## 第五优先级：视觉增强（Dracula + ROS/长时开发向）✅ 已实现

| 功能 | 说明 |
|------|------|
| **主题** | **Dracula-ROS** 默认：`#282a36` 深灰底（非纯黑），ANSI 红/黄/绿分层清晰，便于 **ROS 日志、rqt、长时间扫屏** |
| **状态栏** | 右侧保留**最小必要信息**：**工作区名 + 电量 + 时间**，弱化配色与分隔，减少视觉干扰 |
| **背景与渲染** | **纯色不透明底**；Software 前端、`animation_fps = 1`、禁用 Acrylic，优先降低宿主进程抖动 |
| **字体** | **JetBrains Mono**，连字开启；`font_size = 14` |
| **标签栏** | **Fancy tab bar**；标签与 **Dracula** tab_bar 色一致 |
| **光标与滚动条** | `SteadyBar` 竖线光标、`cursor_thickness = 4`；滚动条拇指 `#6272a4`；隐藏鼠标与 reverse-video cursor 均关闭 |
| **配置重载** | `automatically_reload_config = false`：改配置后手动 `Ctrl+Shift+R`，避免编辑半成品时多窗口连弹错误框 |
| **WSL 启动目录** | 通过 `wsl_domains.default_cwd = '/home/lenovo'` 固定默认进入 home，避免继承到 `/mnt/c/Users/lenovo` |
| **按目录换色** | `/prod/`、`production` → **Dracula-Warn**；`/staging/`、`staging` → **Dracula-Staging**；规则在 `PATH_THEME_RULES`（可加 catkin 工作空间等子串） |

### 测试建议

1. 新开 WezTerm，确认默认落在 `~`（如 `/home/lenovo`），不再继承到 `/mnt/c/Users/lenovo`。
2. 看状态栏是否只显示 **工作区名 / 电量 / 时间**，且视觉不抢眼。
3. `cd` 到路径里带 `staging` / `production` 的目录（或改规则匹配你的目录名），观察整体配色是否按目录切换。
4. 检查稳定竖线光标、黄色分割线和非活动窗格压暗是否清晰。
